Calculadora de Boost PXG

Como funciona

No PokéXGames, subir o boost de um Pokémon segue uma progressão: ir do nível 0 para o 1 custa 1 stone, do 1 para o 2 custa 2 stones, do 2 para o 3 custa 3, e assim por diante até o nível 50.

Para saber quantas stones você gasta de um nível A até um nível B, a calculadora soma a progressão desse intervalo usando a fórmula (B·(B+1) − A·(A+1)) ÷ 2 — o mesmo resultado de somar nível por nível, mas instantâneo.

Do zero ao 50, por exemplo, são 1.275 stones no total. Se você já está no boost 20 e quer chegar ao 35, a calculadora mostra exatamente o que falta para o trecho, sem precisar consultar a tabela de boost nível por nível.

Perguntas frequentes

Quantas stones preciso para o boost 50? Do 0 ao 50 são 1.275 stones (1+2+…+50). Para intervalos menores, use a calculadora acima.

Como o custo de boost é calculado? Cada nível custa o próximo número da sequência: 1 stone para o primeiro ponto, 2 para o segundo, e assim por diante.

Serve para qualquer Pokémon? Sim — a quantidade de stones por nível de boost é igual para todos; o que varia é o efeito do boost em cada Pokémon.
