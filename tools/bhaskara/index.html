Calculadora de Bhaskara

Equação: ax² + bx + c = 0

Como funciona

A ferramenta resolve equações do segundo grau no formato ax² + bx + c = 0 usando a fórmula de Bhaskara, e mostra cada etapa do cálculo — não só o resultado final.

Primeiro é calculado o delta (Δ = b² − 4ac), que indica quantas raízes reais a equação tem: Δ > 0 significa duas raízes diferentes, Δ = 0 significa uma raiz única e Δ < 0 significa nenhuma raiz real.

Depois, as raízes saem de x = (−b ± √Δ) / 2a. A calculadora exibe os valores substituídos em cada fórmula, então dá para conferir o exercício passo a passo ou copiar a resolução para o caderno.

Perguntas frequentes

Qual é a fórmula de Bhaskara? x = (−b ± √Δ) / 2a, com Δ = b² − 4ac, para equações do tipo ax² + bx + c = 0.

O que significa delta negativo? A equação não tem raízes reais: a parábola não toca o eixo x. As raízes só existem nos números complexos.

Quando existe uma única raiz? Quando Δ = 0 — as duas raízes coincidem em x = −b / 2a.
